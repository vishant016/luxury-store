## Environment Variables

### Root / Docker (`docker-compose` / Postgres)

Aligned with Compose: **`medusa_db`**, **`medusa_user`**, **`medusa_pass`**, Postgres `5432`, Redis `6379`.

### Backend `apps/backend-commerce/.env` (example)

```
DATABASE_URL=postgres://medusa_user:medusa_pass@localhost:5432/medusa_db
REDIS_URL=redis://localhost:6379
# Plus Medusa http.cors, JWT/cookie secrets, etc. as generated by the starter
```

### Storefront `apps/storefront/.env.local` (required for API)

```
NEXT_PUBLIC_MEDUSA_BACKEND_URL=http://localhost:9000
NEXT_PUBLIC_MEDUSA_PUBLISHABLE_KEY=<from Medusa Admin or seed log>
NEXT_PUBLIC_STORE_CURRENCY=inr
```

**Before → now:** Original doc listed only `NEXT_PUBLIC_MEDUSA_BACKEND_URL`. The **publishable key** is **mandatory** for Store API calls. **Default display currency** is **INR** (see Commerce / seed below).
